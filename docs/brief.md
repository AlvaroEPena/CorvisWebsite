# Corvis — Brief

_Mode: new · Created: 2026-10-07_

## Pitch

Corvis ("Core Vision") is the owner's own web design business: redesigning existing
websites and building new ones from scratch for businesses. Slogan: **The Core Vision.**
The landing page must look phenomenal, modern, fast, and glassy.

## Type & audience

- Site type: marketing landing page (single page, anchored sections)
- Primary audience: small/mid businesses that need a new or redesigned website (B2B)
- Devices / context: mobile-first and desktop; SEO matters

## Goals

- Primary goal: generate leads: contact form + "Book a free consult" CTA
- Success looks like: visitor understands the offer in 5 s, sees proof, submits the form;
  Lighthouse 95+; looks premium enough to sell web design itself

## Content & accounts

- Who edits content: only developers (content in code); no CMS
- Accounts / roles: none, fully public

## Required features (MVP)

- Hero with slogan "The Core Vision" and strong CTA
- Services (redesign / new build / care plan / etc.)
- Portfolio / case studies (polished placeholder projects until real ones exist)
- Interactive before/after redesign slider (signature demo)
- Process (how we work)
- Pricing / packages ("starting at")
- Testimonials + FAQ
- Contact form with email delivery + "Book a free consult" CTA
- SEO basics: meta, OG image, sitemap, JSON-LD (ProfessionalService), favicon
- Accessible (WCAG AA), reduced-motion respected

## Nice-to-have (later)

- Calendar embed (Cal.com/Calendly), blog, real case studies, analytics, @domain email

## Constraints

- Hosting / budget: Cloudflare free tier (Workers static assets)
- Tech preferences: none; must be very fast
- Compliance: contact form stores/forwards personal data, so a privacy note and spam protection are needed
- Timeline: none stated

## Design

- Brand assets: none; logo/wordmark and palette designed by us
- Reference sites: the supplied image (light frosted glass, pearl background,
  translucent cards, glossy gradient panels in orange and deep green, soft 3D floating
  objects, pill buttons) and https://www.marketu.com/
- Direction: light frosted glass, soft 3D. Palette is our choice, derived from the name
  (core + vision)
- Tone of voice: confident, clear, premium, not jargon-heavy
